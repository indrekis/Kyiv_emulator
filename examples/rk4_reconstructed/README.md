# RK4 n=2 — функціональна реконструкція (H113)

**Це інтегровані тести доказів, а не історична реконструкція ПЗП.** Оригінальні команди RK4 `3600–3676` виконувалися production CPU в H109–H111; машинні RHS — синтетичні, друк H103 — реконструйований, початкові невідомі слова `3200` і `3677` не відновлені. Додаткові припущення про початкові комірки залишаються припущеннями.

## Офлайнова демонстрація

Після встановлення H113 у корінь Git checkout:

```bash
python -m unittest discover -s examples/rk4_reconstructed/tests -p 'test_*.py' -v && \
python examples/rk4_reconstructed/run.py --out tempkyiv/H113_OFFLINE_EVIDENCE_V1 && \
unzip -t tempkyiv/H113_OFFLINE_EVIDENCE_V1.zip && \
git diff --check && git status --short
```

`--out` має вказувати **нову** директорію. Скрипт зупиняється без перезапису наявних доказів. У виході створюються `RESULT_H113.json`, результати H112, відтворений `DEMO_H112.html` і ZIP з журналами. Дивитися HTML можна локально у браузері. Python 3.10+; зовнішні Python пакети й мережа **не потрібні**.

Збережений в `bundle/` H112-H1 архів зафіксований SHA-256 і перевіряється перед виконанням. Для відтворення native-виконання потрібно окремо розпакувати H112-H1 і запускати його `h112_replay.py` з установленим MSYS2/MINGW64 середовищем; **CI H113 не запускає CPU заново**.

## CI

`.github/workflows/kyiv-rk4-evidence.yml` запускає той самий офлайновий контроль на Ubuntu і Windows. Робота CI не означає кваліфікацію нативного білдів на цих системах: вона перевіряє зафіксовані *раніше* native-evidence, їх цілісність, 29 сценаріїв, 3408 точок та побайтове відтворення HTML.

## Межі

- Повне RK4 **n=2** для трьох перевірених систем; не n>2.
- H103 кваліфікований лише як машинний модуль виведення n=1…8; це не доказ n>2 RK4.
- Оригінальний історичний принтер і ПЗП `3200`, `3677` залишаються невідомими.
- Звіти та CI не є новою історичною документацією й не підтверджують фізичну точність апаратури.
- `docs/historical/ROADMAP.md` H113 не редагує. Пропозиція його доповнення є всередині H112-H1.

Прочитай `RELEASE_NOTES_H113.md` перед публікацією. Не включай сюди PDF-скани без окремої перевірки прав на розповсюдження.
