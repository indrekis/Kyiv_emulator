# ISA-06 D8-P3 — uninterrupted fourth-RAM-test write/read sweep (conditional qualification)

**Baseline:** Git `de55204` (D8-P2). **Scope:** one new C++ probe, provenance and gate notes, a Python structural auditor. **No changes** to CPU, ROM, prior tests, historical corpus, or top-level README. All proposed end-to-end assertions are **POLICY**, not historical `STRICT`; the probe must pass on the user's native build before commit.

## Primary source and boundaries

Glushkov–Yushchenko, *Vychislitel'naya mashina «Kiev»* (1962), Appendix 2, **printed pp. 170–171**, scan PDF physical pages **169–170** (zero-based PDF pages 168–169). Printed p.170 describes fourth RAM test as write `0122–0136`, read `0140–0155`; printed p.171 supplies every machine word. The **six bridge/entry commands** outside the D5/P2 27-word window are copied as original octal constants, not generated by the project's assembler:

| Original PC (octal) | Original word (octal field grouping) | Role |
|---|---|---|
| `0120` | `01 3012 0000 0017` | Initialize traveling pattern source |
| `0121` | `01 0017 0000 0021` | Copy pattern to working cell |
| `0137` | `01 0017 0000 0021` | Natural transition after write sweep |
| `0156` | `13 3012 0017 0017` | Advance pattern source after read sweep |
| `0157` | `16 0017 3042 0161` | Test pattern against injected ROM constant |
| `0160` | `05 0000 0000 0121` | Equality-dependent reentry — **ISA-05 POLICY** |

The remaining **27** historical body words are duplicated from D5/P2 and checked by the new auditor. The complete scope here is **33** original instructions, **not** a statement that the complete historic diagnostic ROM or its setup was authenticated.

## Controlled initial environment, NOT historical initialization

The test invokes a fresh `Kyiv_t` and injects ROM `[3012]=+1`, `[3026]=-0` (sign bit set), `[3042]=highest magnitude bit`, as in D5/P2; it bypasses the CWD-dependent constructor ROM loader. RAM `[0014]=+0` deliberately selects the positive sign branch, while `[0017]`, `[0020]`, `[0021]` start at sentinel `077` and are overwritten by the original code. Data RAM `[0200..1777]` is prefilled with sentinel `077`. Registers: `C=0120`, `A=0`, `Cy=077`, `P=0371`, `T=false`. **None** is certified as an original front-panel startup state.

Only the **positive sign-of-0014 branch** is exercised. In particular ROM `[3036]` needed for opposite sign-control branches is **not** authenticated or injected, and those paths remain outside scope. All RAM words, including the `-0` marker, are checked as full 41-bit codes. **No external phase reset** is performed.

## Natural execution and qualification gates

The test executes one uninterrupted sweep starting at historical `0120`; it stops when original `0160` returns naturally to `0121` (before the next pattern pass). The two loops cover data addresses `0200..1777` inclusive, i.e. **896 addresses** (octal), bounded at 25,000 machine steps.

| Gate | Expected observation / qualifying condition | Class |
|---|---|---|
| `0120→0121→0122` | Both original startup copy operations execute; no harness phase switch | POLICY — injected ROM |
| `0126` loop | Every one of 896 addresses receives the **full original code** in RAM `[0020]`; first divergence records PC and K | POLICY — sign-of-zero `01`, `05` branch equality |
| `0136→0137→0140` | Original loop terminates; `0137` transfers the working pattern; natural handoff from write to read (without assigning C/A/Cy manually) | POLICY |
| `0144` loop | 896 original exact comparisons succeed; independently preserved write snapshot equals later read data, including `-0` if present | POLICY; `016` comparison itself is separately STRICT in D7 |
| `0155→0156→0157→0160→0121` | Natural read termination, shift of pattern source, first reentry (via existing opcode 05 equality **POLICY**) | POLICY |

The executed K must match the literal original word at **every step**; unexpected PC, STOP, memory alteration, address repetition, or step-budget exhaustion fails the POLICY gate and prints the **first bad PC, fetched instruction K, reason, and counts**. No manual alteration of C, A, Cy, RAM `[0021]`, or RAM `[0020]` is permitted after setup. The tester reports counts of observed `-0` write/read locations; their exact count is not an independent hardware oracle.

## Independence and limitations

A passing P3 is **much stronger internal consistency evidence** than P2's four 8-step phase snippets: P3 executes original startup and phase handoffs uninterrupted. It still **does not prove** that the original Kyiv machine used the current signed-zero `01` rule, that the three ROM constants are authentic, that the `05` equality branch is historically correct, or that startup memory matches a documented operator procedure. These remain `POLICY` / `OPEN`. A failed P3 must not automatically induce an emulator fix: first inspect the first divergence, its fixture assumptions, and the actual original word.

The Python structural audit checks D5 and P2 immutable Git blob identities, exact historical body-word equality, the six new bridge-word literals, expected evidence records and the absence of trailing whitespace. It is not an execution oracle. All source SHA-256 checks normalize **only** CRLF to LF; Git blob checks are independent of checkout line endings. `H2 E022` remains retracted; D8-H1–H9 remain documentary.
