## 3. Історична невизначеність — **не закрита**

Друкована с. 114 видання Глушкова й Ющенко (1962) містить безумовне додавання `+1/2` у команді `3367`. На нинішній моделі машини негативне переповнення в початковому RK4 давало `+15/64` замість `−113/64`. Приватна машинна гілка H115-B19 виправила цей випадок; його успіх доведений нативно **для функціонального ROM**.

Водночас немає незалежного доказу, що така сама помилка існувала у фізичній машині чи в реально змонтованому змінно-спаяному блоці: можливі помилка друку, інша редакція програми або неповно відтворена особливість апаратури (зокрема механізму переповнення). Усі синтетичні слова залишаються явно такими. Детальний реєстр — [`H115_FP_ROM_PRINTED_VS_FUNCTIONAL.md`](H115_FP_ROM_PRINTED_VS_FUNCTIONAL.md).

У `examples/fp_rk4_reconstructed/PROVENANCE.json` поле `open_defect` документує **історичний стан на момент H115-B18**, до H115-B19. Це не поточний статус функціонального ROM. Залишаємо початковий provenance недоторканим, щоб не переписувати історію перевірок.

## 4. Відтворення на поточному емуляторі

У MSYS2 MINGW64 із кореня Git checkout:

```sh
mkdir -p tempkyiv && \
g++ -std=c++17 -O0 -Iinc src/main.cpp src/asm_disasm.cpp -o tempkyiv/kyivemu_fp.exe && \
ROM=examples/fp_rom_reconstructed/inputs/FP_FUNCTIONAL_1962_RECONSTRUCTED.k41 && \
SHA=$(sha256sum "$ROM" | cut -d' ' -f1) && \
./tempkyiv/kyivemu_fp.exe fp-image \
  examples/fp_affine_recurrence/inputs/AFFINE_RECURRENCE.k41 \
  0300 2500 --fp-rom "$ROM" --fp-sha256 "$SHA" \
  --end-pointer 0306 --watch 0100 --watch 0103
```

Очікування: `H115-FP-RUN STATUS=END_POINTER`, `C=3305`, `POINTER=0306`, `DISPATCHES=24`, `0100=17400000000077` (31/64), `0103=10000000000101` (1).

Офлайновий контроль:

```sh
python -B -m unittest discover -s examples/fp_affine_recurrence/tests -p 'test_*.py' -v && \
python -B -m unittest discover -s examples/fp_rom_reconstructed/tests -p 'test_*.py' -v && \
python -B -m unittest discover -s tests/historical -p 'test_h115_fp_closure.py' -v
```

Офлайновий аудит звіряє збережені докази; **він не створює нового нативного виконання**. Вимоги до справжньої історичної автентичності (оригінальний монтаж ROM, незалежна звірка першоджерела, апаратна семантика) залишаються відкритими.

## 5. Межі цього закриття

- Не змінюємо `src/main.cpp`, `inc/kyiv.h`, `mem/ROM.txt`, історичний `.k41` чи постійні образи Ейлера та RK4.
- Не змінюємо існуючий користувацький `docs/historical/ROADMAP.md`; його узгодження — окрема дія.
- Підсумок H115 означає функціональну готовність **у перевіреному діапазоні**, а не повне покриття кожної FP-команди, винятку чи фізичного обладнання.
- Наступні функції емулятора можна розвивати незалежно; знайдені надалі FP-дефекти реєструвати окремими регресіями.
