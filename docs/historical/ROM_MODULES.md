# ЕОМ «Київ»: каталог модулів змінно-спаяної ПЗП — початок етапу C

**Стан:** `C1_SOURCE_INVENTORY`, машинні слова ще не транскрибовані і не встановлені в емулятор. **Першоджерело:** Глушков, Ющенко, 1962, друк. с. 93–95.

## Незалежні складники пам'яті

- `3010–3277` — постійно-спаяна ПЗП (ПСП), зафіксована у поточному `mem/ROM.txt`; не копіювати та не переписувати її для змінного модуля.
- `3300–3777` — змінно-спаяні адреси, що потребують **обраного комплекту** блоків та атрибуції кожного слова. Не ініціалізувати відсутні адреси нулями як історичним вмістом.
- Окрема адреса `0360` належить ОЗП і не пов'язана з `3360` або з джерелом блоку № 1.

## Модуль № 1: один документований комплект, слот `3300–3377`

| Область, вісімкова | Призначення | Старт / стан |
|---|---|---|
| `3300–3317` | Корінь квадратний, `0 ≤ a < 1`, `RAM[0002]` → `RAM[0003]` | `3300`, `SOURCE_PRINTED`, транслітерація `OPEN` |
| `3320–3333` | Скалярний добуток двох векторів через α-послідовності | `3320`, `SOURCE_PRINTED`, транслітерація `OPEN` |
| `3334–3357` | Матриця × вектор | `3334`, `SOURCE_PRINTED`, транслітерація `OPEN` |
| `3360–3374` | Степенева функція з використанням бібліотечної підпрограми ln | `3360`, `SOURCE_PRINTED`, транслітерація `OPEN` |
| `3375–3377` | Три константи | `SOURCE_PRINTED`, транслітерація `OPEN` |

Сума розмірів: `16 + 12 + 20 + 13 + 3 = 64` комірки (вісімкова область із 64 десяткових адрес). У текстовому описі скалярного добутку на с. 94 може читатися `3200–3333`, водночас явно вказано старт `3320` і під ним надрукований машинний лістинг; **не виправляти оригінальну друкарську неоднозначність без позначки**.

## Наступний H54 / C1

1. Незалежно транскрибувати 64 слова з **двох** зображень с. 94–95, із подвійною верифікацією неоднозначних символів (наприклад, `ЗОН` у OCR не є вісімковим кодом).
2. Створити окремий `words.k41` із provenance, SHA, сторінкою та номером стовпчика/рядка; не додавати код у `mem/ROM.txt` і не змінювати образи АУ.
3. Створити вузький валідатор: дозволена область слоту, 64 унікальні адреси, обмеження 41 біт, відсутність колізій із фіксованою ПСП, негативні тести, атомарне перемикання комплектів.
4. Лише після цього — нативна діагностична демонстрація `3300` (корінь квадратний) з незалежним чисельним еталоном і відокремленням `HOST`-початкового стану.

**Не встановлено:** історичний фізичний модуль, реальна конфігурація всіх слотів, робота пульта перемикання блоків та фізичний еталон.
